# Publicacion en GitHub Pages

## Opcion recomendada

Sube esta carpeta como el contenido raiz del repositorio.

La estructura debe quedar asi:

```text
index.html
manifest.webmanifest
service-worker.js
jetta-icon.svg
README.md
docs/
```

## Activar GitHub Pages

1. Abre el repositorio en GitHub.
2. Entra a **Settings**.
3. Abre **Pages**.
4. En **Source**, elige `Deploy from a branch`.
5. En **Branch**, elige `main`.
6. En carpeta, deja `/root`.
7. Guarda.

Despues de unos minutos, GitHub mostrara la URL de la app.

## Nota sobre datos

GitHub Pages publica el codigo de la app. Los datos del vehiculo se guardan localmente en cada navegador.

Si abres la app publicada en otro navegador, empezara sin datos hasta que importes un respaldo.
