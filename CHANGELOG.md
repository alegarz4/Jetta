# Changelog

## Version 5

- Boton **Actualizar app** para limpiar cache y cargar cambios publicados en GitHub.
- Service worker ajustado para activar versiones nuevas mas rapido.
- La navegacion principal intenta cargar desde red antes que cache cuando hay conexion.

## Version 4

- Iconos PNG de 192 y 512 px para mejorar compatibilidad de instalacion en celular.
- Manifiesto actualizado para navegadores moviles.
- Cache de app actualizado a `mi-jetta-app-v4`.

## Version 3

- Nueva pestaña **Sonidos** para orientar fallas por ruido.
- Nueva pestaña **Graficas** con rendimiento por carga.
- Grafica de gastos por mes.
- Grafica de gastos por categoria.
- Lectura rapida de tendencias de consumo.
- Documentacion actualizada para las nuevas funciones.

## Version 2

- Guardado automatico mas consistente.
- Confirmacion antes de reiniciar o eliminar registros.
- Exportacion e importacion de respaldos JSON.
- Carga automatica de datos guardados.
- Calculo de rendimiento de gasolina ajustado.
- Fechas con selector de calendario.
- Categorias de gastos con lista desplegable.
- Registros nuevos con fecha y kilometraje actual.
- Formato de moneda en pesos mexicanos.
- Archivos basicos para instalacion como app web.
