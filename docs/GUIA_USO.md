# Guia de uso

## Perfil

Captura los datos generales del vehiculo. El campo mas importante es **Kilometraje actual**, porque de ahi salen las alertas de mantenimiento.

## Mantenimiento

Registra el ultimo kilometraje y el proximo kilometraje de cada servicio. La app marca cada servicio como:

- **Bien**: aun hay margen.
- **Proximo**: conviene planearlo.
- **Urgente**: falta poco.
- **Vencido**: ya paso el kilometraje recomendado.

## Historial

Guarda servicios realizados y fallas detectadas. Esto sirve para recordar que se hizo, cuanto costo y si una falla quedo resuelta.

## Gasolina

Agrega cada carga con fecha, kilometraje, litros y costo.

Para que el rendimiento sea mas confiable, registra cargas consecutivas. La primera carga sirve como punto de partida; desde la segunda la app puede calcular consumo por tramo.

## Gastos

Registra pagos por categoria: gasolina, mantenimiento, refacciones, verificacion, seguro, estacionamiento, lavado u otros.

## Diagnostico

Marca sintomas actuales. La app ofrece una orientacion inicial para decidir que revisar primero, pero no sustituye revision mecanica ni escaneo OBD.

## Respaldos

Usa **Respaldar** antes de cambiar de dispositivo, limpiar el navegador o hacer pruebas.

Usa **Importar** para restaurar un archivo `.json` generado por la app.
